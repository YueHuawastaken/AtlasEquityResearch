# Atlas Equity Research

Independent equity research platform scaffolded as a production-oriented monorepo.

## Structure

- `client/` React, TypeScript, Vite, Tailwind-ready UI shell
- `server/` Express, JWT auth scaffold, API foundation
- `shared/` cross-cutting domain types
- `prisma/` PostgreSQL schema centered on companies

## Phase 1 scope

- App shell and routing
- Institutional navbar, footer, and theme
- Landing page foundation with API-backed stats
- Auth middleware scaffold
- Initial Prisma schema
